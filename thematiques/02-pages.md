# Écrans et navigation

Une application mobile, c'est avant tout des écrans. Les *pages* s'articulent autour de 3 axes principaux :
- **Layout** : comment *dessiner* des éléments pour composer un écran
- **Évènements** : comment réagir aux volontés de l'utilisateur
- **Navigation** : comment passer d'un écran à l'autre

C'est ici que le storyboard prend vie : chaque écran de la maquette devient une page réelle,
reliée aux autres par la navigation Shell.

**À l'issue de cette thématique, vous serez capable de :**
- composer un écran avec les layouts principaux (`Grid`, `VerticalStackLayout`, `HorizontalStackLayout`)
- relier un évènement (clic de bouton) vers du code C# (*code-behind*)
- structurer la navigation d'une application avec le Shell
- passer des paramètres d'une page à l'autre
